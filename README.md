# Rayo Company — موقع تعريفي (Static)

موقع HTML/CSS/JS ثابت (صفحة `Rayo.html`) — لا يحتاج PHP ولا قاعدة بيانات.

## التشغيل
- الطريقة 1: افتح `Rayo.html` مباشرة في المتصفح
- الطريقة 2 (الأفضل): من VS Code بامتداد Live Server ← `Open with Live Server`
- أو انسخه إلى `htdocs/Rayo-Company` وافتح `http://localhost/Rayo-Company/Rayo.html`
